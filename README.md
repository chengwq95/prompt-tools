# Prompt Tools

A collection of browser tools for writing AI image and video prompts.

**Live:** https://chengwq95.github.io/prompt-tools/

## Use online

| Tool | Description | Open | Source |
| --- | --- | --- | --- |
| **AI Image Prompt Builder** | Build English or Chinese image prompts from four blocks: Time, Subject, Scene, and Style. | [Open](https://ai-image-prompt-builder.pages.dev/) | [Source](https://github.com/chengwq95/ai-image-prompt-builder) |
| **AI Video Prompt Builder** | Create copy-ready English prompts for character images, director scripts, still images, and image-to-video shots. | [Open](https://ai-video-prompt-builder.pages.dev/) | [Source](https://github.com/chengwq95/ai-video-prompt-builder) |

## About this collection

This repository is a simple directory for the tools above. Each tool remains independently developed and hosted in its own repository.

Want to use a tool locally? Clone its repository and open its `index.html` file in a browser.
